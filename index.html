Asymmetric MHQ Formula (-100 to +200)

Raw item ratings r ∈ [1, 9] are anchored at functional baseline r = 4 → 0:

if r < 4:  MHQ(r) = ((r - 4) / 3) * 100   // [-100, 0)
if r ≥ 4:  MHQ(r) = ((r - 4) / 5) * 200   // [0, +200]

Dimension scores average 4 items; overall MHQ averages all 6 dimensions.

Offline-First PWA Architecture

  • App Shell Precache: Service Worker (sw.js) caches HTML, CSS, ES modules, manifest, and SVG icons on install.
  • Cache-First Fetch: Instant offline boot with zero remote CDN dependencies.
  • Local Persistence: IndexedDB store mhq_reports_db with localStorage & memory fallback.
  • PDF Export: Pure vector SVG charts + dedicated @media print layout.
